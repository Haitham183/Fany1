# منظومة إدارة مدارس التعليم الفني الصناعي المصرية (منهجية الجدارات المهنية - CBE)

نظام متكامل لإدارة وتقييم مدارس التعليم الفني الصناعي المطبقة لمنهجية الجدارات المهنية وفقاً لقرارات وزارة التربية والتعليم والتعليم الفني وقانون التعليم رقم 139 لسنة 1981.

---

## المزايا والخصائص الأساسية

1. **إدارة الجدارات المهنية (CBE Matrix)**:
   - آلة حالات مطابقة للائحة التقييم والتحقق (فرصة 1 -> فرصة 2 -> برنامج علاجي -> دور ثانٍ -> إعادة السنة في الوحدات غير المجتازة فقط -> نظام العمال).
   - توثيق الأدلة الثلاثة (دليل أداء / دليل منتج / دليل تساؤل).
   - سجل التظلمات على التقييمات وقرارات اللجان.
   - تقويم زمني مجدول لفترات التحقق والبرامج العلاجية.

2. **التحقق الداخلي والخارجي (IV & EV Engine)**:
   - توليد عينات عشوائية متماثلة (Seeded PRNG) قابلة لإعادة الفحص والتحقق.
   - محاضر زيارة واعتماد معتمدة ومجهزة للطباعة.

3. **الحضور والغياب وقانون التعليم 139 لسنة 1981**:
   - مؤشر مزدوج (نسبة مئوية + عداد أيام وساعات فعلي تراكمي).
   - عتبة الحد الأدنى للأيام (10 أيام) قبل تفعيل إنذارات النسبة.
   - تطبيق المادة 25 (إنذار أول عند 5 متصل / 10 منفصل، إنذار ثان عند 10 متصل / 20 منفصل، فصل عند 15 متصل / 30 منفصل).
   - قواعد حضور الورش الإلزامية (85%).
   - إعادة القيد بإيصالات 33 ع.ح وسداد الرسوم المقررة.

4. **محرك الإنذار المبكر الشفاف**:
   - تحليل شفاف لمخاطر التعثر والتسرب بناءً على أوزان محددة ومفصلة.
   - اعتماد بشري صريح قبل أي إحالة للأخصائي الاجتماعي.

5. **الأمان وحماية البيانات (PII Security)**:
   - تخزين آمن ومشفر محلياً باستخدام Dexie IndexedDB مع تجزئة الأرقام القومية.
   - سياسات أمان متقدمة Row Level Security (RLS) ومصفوفة صلاحيات (V/C/A) لـ 8 أدوار مع شارة المحقق الداخلي.
   - سجل تدقيق غير قابل للتعديل (Insert-Only Audit Log).
   - بوابة آمنة لأولياء الأمور بتسجيل دخول ثنائي ومحدد معدل الطلبات (Rate Limiting).

6. **الشيتات والسجلات المدرسية الرسمية**:
   - شيت 1 سر الشهري، سجل 41 للمستجدين، سجل 5 مواظبة، استمارات تقييم الجدارات.
   - ترويسة مدرسية مخصصة وعلامة مائية رسمية "مسودة تحتاج مطابقة مع دفاتر المدرسة".

## متطلبات التشغيل والتطوير

- **Node.js**: الإصدار 18 فما فوق
- **npm** أو **yarn** أو **pnpm**

---

## التثبيت والتشغيل المحلي

```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل بيئة التطوير
npm run dev

# تشغيل حزمة الاختبارات الآلية
npm test

# بناء النسخة الإنتاجية
npm run build
```

## بنية المشروع

```text
├── src/
│   ├── app/                 # صفحات وتوجيهات Next.js App Router
│   ├── components/          # واجهات المستخدم وبوابات الأدوار المختلفة
│   ├── lib/
│   │   ├── auditLogger.ts   # محرك سجل التدقيق الأمني
│   │   ├── cbeStateMachine.ts # آلة حالات التقييم والتحقق
│   │   ├── db.ts            # قاعدة بيانات Dexie IndexedDB
│   │   ├── earlyWarningEngine.ts # محرك الإنذار المبكر
│   │   ├── migration.ts     # محرك الهجرة وتشفير البيانات
│   │   ├── permissions.ts   # مصفوفة الصلاحيات وفصل المهام
│   │   ├── storage.ts       # محرك إدارة البيانات والتخزين
│   │   ├── terms.ts         # القاموس الرسمي للمصطلحات
│   │   └── verificationEngine.ts # محرك العينات العشوائية المتماثلة
│   └── types/               # تعريفات TypeScript الرسمية
├── supabase/
│   └── migrations/          # ملفات تهجرة قواعد البيانات وRLS والتشفير
├── tests/                   # اختبارات الوحدة الشاملة (Vitest)
├── CHANGELOG-v2.md          # سجل التغييرات والتحديثات اللائحية
└── package.json
```
